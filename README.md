# YouTube Comment Replier

Автоматизация ответов под комментариями YouTube: скрытые (stealth) сессии Camoufox, несколько аккаунтов, ответы пишет DeepSeek, а возраст и состояние аккаунтов отслеживает движок жизненного цикла.

> Проект работает с реальными аккаунтами YouTube. Используйте его только со своими аккаунтами и в рамках правил площадки.

## Возможности

- **Мультиаккаунтность.** Отдельный постоянный профиль браузера и прокси для каждого аккаунта.
- **Жизненный цикл аккаунтов.** Стадии `карантин → aging → probation → mature`, суточные квоты и circuit breaker. Новые аккаунты не комментируют, пока не пройдут прогрев.
- **Прогрев.** Органический просмотр ленты и видео для карантинных аккаунтов, с запасным поиском, если лента пуста.
- **Heartbeat сессий.** Лёгкая проверка, что вход в аккаунт жив, без открытия браузера.
- **Ответы через DeepSeek.** Шаблоны стилей, перефразирование, контроль языка и длины.
- **Интерактивный мастер.** Настройка и запуск в консоли: аккаунты (импорт файлом или вставкой, прогрев, таблица жизненного цикла), прокси, ключ DeepSeek, цели.
- **Безопасное хранение.** Пароли и TOTP-секреты шифруются в SQLite через Windows DPAPI.

## Требования

- Windows 10/11 (шифрование секретов использует DPAPI)
- Python 3.12
- Ключ API DeepSeek

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m camoufox fetch
```

Скопируйте шаблон конфигурации и заполните его:

```bash
copy config.example.yaml config.yaml
```

`config.yaml` содержит ключи и аккаунты, поэтому в git он не хранится (см. `.gitignore`). Ключ DeepSeek можно ввести и в мастере.

## Запуск

Интерактивный мастер (основной способ):

```bash
python youtube_bot.py --wizard
```

Часто используемые команды:

| Команда | Что делает |
|---|---|
| `python youtube_bot.py --auth-account <имя>` | Вход в один аккаунт |
| `python youtube_bot.py --import-accounts-file <путь>` | Пакетный импорт аккаунтов и вход в них по очереди |
| `python youtube_bot.py --list-accounts` | Список аккаунтов |
| `python youtube_bot.py --lifecycle` | Таблица стадий жизненного цикла |
| `python youtube_bot.py --warm-quarantined` | Прогрев карантинных аккаунтов |
| `python youtube_bot.py --search "<тема>" --min-views 10000 --max-views 500000 --dry-run` | Поиск видео и ответы (пробный запуск) |
| `python youtube_bot.py --status` | Состояние базы данных |

Формат строки при импорте: `логин:пароль:TOTP-секрет`, по одной на аккаунт.

## Разработка

```bash
python run_tests.py
```

Правила проекта (структурные селекторы YouTube, шифрование секретов, многопроцессный Gecko, async везде) описаны в `AGENTS.md` и `CLAUDE.md`. Память проекта ведётся через MEX: `mex doctor` и `mex check`.

## Структура

| Путь | Назначение |
|---|---|
| `youtube_bot.py` | Точка входа и CLI |
| `modules/` | Мастер, оркестратор, движок жизненного цикла, прогрев, heartbeat |
| `database.py` | Работа с SQLite (aiosqlite) |
| `secret_store.py` | Шифрование секретов (DPAPI) |
| `config.example.yaml` | Шаблон конфигурации |
| `tests/` | Тесты (unittest) |
| `.mex/` | Память проекта |

## Безопасность

Не коммитьте `config.yaml`, файлы с аккаунтами, профили браузеров (`test_sessions/`) и базы данных. Они перечислены в `.gitignore`. Если секрет попал в историю git, считайте его скомпрометированным и замените.
